Lab 2: Supervised ML with Teachable Machine

Lab 2, Page 3

In machine learning, a class is like a category or a bucket that the computer learns to sort things into. For example, you could train a computer to understand the difference between images of cats and images of dogs by showing it lots of images of both animals and telling it which animal each picture is. That project would have two classes: cats and dogs.

Lab 2, Page 4

In machine learning, a model is like a recipe that helps a computer find patterns in data. In this project, your model will learn to sort data into classes (like "spam" vs. "not spam," or "cat" vs. "dog").

Models need to be trained. Training a model means teaching the computer how to sort the data by showing it many examples already labeled with the right class. Over time, the model learns rules to sort new data correctly.

Lab 2, Page 4

Reminder: supervised learning is a type of AI that uses a pre-labeled training set to categorize new data.

Lab 2, Page 5

A probability is a measure of how likely an event is to happen. Probability is described using a number from 0 (impossible) to 1 (certain). For example, you might calculate the chance of flipping a coin and getting heads: the probability is 1/2 or 0.5, which is 50%.

Lab 4: Generative AI with N-grams

Lab 4, Page 1

Generative AI, or GenAI, produces new text, images, music, based on patterns in a (usually very large) set of data.

Lab 4, Page 3: Data, Context, Candidate

Data are basic, raw information (numbers, text, images, audio, etc.).

Context is relevant background information.

Candidates are all the suitable likely choices.

Lab 4, Page 4: Algorithm

An algorithm is a set of instructions, or a sequence of steps, usually performed by a computer.

Lab 4, Page 4: Token

In AI, a token is the smallest unit of data. You can choose the token size that makes the most sense for your model. We are using words as our token, but you could also choose a smaller token, like letters (so that your data is a collection of individual letters) or a larger token, like sentences.

Lab 4, Page 4: N-gram

An n-gram is a chunk of n connected tokens from the data. In our example, words are our token, so an n-gram is any n connected words in our 24-word story. Since our data has 24 words, n can be any number from 1 to 24. You can have 2-grams, like "curious student" or "student enters," or 5-grams, like "enters a science lab. The."
